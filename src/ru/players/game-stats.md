<p class="docs-lead">Страница статистики открыта для всех, включая гостей. Она показывает шесть итоговых чисел и пять графиков, отражающих активность по постам, эпизодам, персонажам и фракциям за любой выбранный период.</p>

## Временной период

В верхней части страницы доступны пять пресетов:

| Пресет | Охватываемый период |
|---|---|
| С начала недели | С понедельника текущей недели по сегодня |
| С начала месяца | С 1-го числа текущего месяца по сегодня |
| Прошлая неделя | Предыдущий понедельник–воскресенье |
| Прошлый месяц | Полный предыдущий календарный месяц |
| Произвольный | Диапазон дат на ваш выбор |

По умолчанию при загрузке выбирается **С начала месяца**. Все периоды привязаны к вашему часовому поясу — страница отправляет ваше смещение UTC на сервер, чтобы границы дней совпадали с вашими часами, а не серверными.

## Итоговые карточки

В верхней части отображаются шесть чисел, каждое за выбранный период:

- **Новые эпизоды** — эпизоды, открытые за период
- **Завершённые эпизоды** — эпизоды, получившие статус завершённых
- **Заархивированные эпизоды** — эпизоды, переведённые в архив
- **Всего постов** — написанные игровые посты (только посты в эпизодах, без внеигровых тем)
- **Разыскиваемые персонажи** — созданные объявления о желаемых персонажах
- **Принятые персонажи** — персонажи, чьи анкеты были приняты и стали активными

## Графики

### Активность написания

Линейный график с одной точкой на каждый день периода. Дни без постов отображаются как ноль — линия не прерывается. В начале каждого месяца показывается название месяца; остальные дни отображают число.

### Лучшие авторы

Горизонтальная гистограмма десяти наиболее активных авторов по количеству игровых постов за период.

### Лучшие персонажи

Горизонтальная гистограмма десяти наиболее активных персонажей по количеству игровых постов. Маски (альтернативные облики персонажа) отображаются как отдельные записи, независимо от основного персонажа.

### Эпизоды по фракциям

Горизонтальная составная гистограмма, по одной полосе на фракцию. Каждая полоса состоит из трёх сегментов: **Созданные** (зелёный), **Завершённые** (синий), **Заархивированные** (красный). Эпизод засчитывается фракции, если хотя бы один из его участников принадлежит этой фракции. Фракции без активности за период не отображаются.

### Посты по фракциям

Вертикальная гистограмма количества постов по фракциям. Учитываются только посты, написанные **от лица персонажа** — ГМ-посты и посты без персонажного профиля в этот подсчёт не входят.

## Кто может видеть статистику

Страница статистики полностью публична. Аккаунт не нужен, и все видят одни и те же данные.
