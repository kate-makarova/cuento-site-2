<p class="docs-lead">Панели виджетов — это настраиваемые области контента, которые отображаются в шапке и подвале форума. Каждая панель представляет собой документ в формате BBCode — не HTML — и может содержать текст, форматирование, изображения и встроенные виджеты.</p>

## Панели виджетов

Панели идентифицируются фиксированным ключом. По умолчанию существуют две панели: `header` (шапка) и `footer` (подвал). Редактируются в разделе **Администратор → Панели виджетов**.

Содержимое панели пишется на **BBCode** — том же синтаксисе, что используется для постов. Стандартные теги форматирования работают как обычно. Чтобы встроить виджет в панель, используйте:

```
[widget=N]
```

где `N` — числовой идентификатор виджета. Бэкенд разбирает BBCode, а затем заменяет каждый тег `[widget=N]` отрендеренным содержимым виджета.

Кнопка **Предпросмотр** рендерит панель без сохранения, чтобы можно было проверить результат перед публикацией.

---

## Виджеты

Виджеты — это переиспользуемые блоки контента, создаваемые в разделе **Администратор → Виджеты**. Каждый виджет имеет название, тип и специфичные для типа настройки. После создания виджет встраивается в любую панель с помощью `[widget=N]`.

---

## Типы виджетов

### Последний пост

Отображает самый последний пост из указанной темы, отрендеренный в HTML. Удобно для закреплённого объявления, краткого изложения правил или любого контента, который управляется через обычный пост темы, но должен отображаться на каждой странице.

- **Тема** — тема, из которой берётся последний пост.

---

### Случайные объекты

Отображает случайно выбранный набор персонажей или желаемых персонажей, опционально показывая для каждого кастомные поля. Набор может автоматически меняться по таймеру, циклически заменяя отображаемые записи новыми без перезагрузки страницы.

**Настройка:**

| Поле | Назначение |
|---|---|
| **Тип объекта** | `character` (персонаж) или `wanted_character` (желаемый персонаж) |
| **Количество** | Сколько объектов показывать одновременно |
| **Интервал ротации** | Время в миллисекундах между сменами. `0` — отключить ротацию |
| **Поле 1 / Поле 2** | Машинное имя кастомного поля для отображения рядом с каждым объектом (необязательно) |
| **Ширина / Высота** | Размеры отображения в пикселях для каждого поля-изображения |
| **Фильтры** | Опционально ограничить по статусу персонажа или только незаявленными желаемыми персонажами |

Каждый отображаемый объект ссылается на профиль персонажа или тему желаемого персонажа.

#### Поля изображений и генерация миниатюр

При выборе кастомного поля типа «изображение» значения **Ширины** и **Высоты** определяют, как именно изображение отображается.

Поведение зависит от типа рендеринга поля и от того, настроен ли прокси изображений:

**Обычное поле изображения** (тип рендеринга `image`): ширина и высота передаются фронтенду только как размеры отображения. Оригинальный URL используется как есть — изменение размера на стороне сервера не выполняется.

**Поле обрезанного изображения** (тип рендеринга `cropped_image`) при включённом прокси изображений (настройка `use_image_uploading` = `y`): бэкенд генерирует точную обрезку по заданным размерам:
1. Проверяет кэш ранее сгенерированной обрезки для этого URL и размера
2. Загружает оригинальное изображение
3. Обрезает и изменяет размер до точных ширины × высоты с центрированием и ресемплингом Lanczos
4. Кодирует в JPEG с качеством 85
5. Загружает на настроенный хостинг изображений и кэширует результат

Последующие запросы на то же изображение с теми же размерами обслуживаются из кэша без повторной обработки.

Если прокси изображений не настроен, оригинальный URL возвращается как есть, даже для полей `cropped_image`.

Ширина и высота определяют точные размеры в пикселях итоговой обрезки — устанавливайте их в соответствии с размером блока, который занимает виджет, чтобы избежать размытого увеличения или лишней нагрузки от слишком большого оригинала.

---

## Советы

- Виджет можно переиспользовать в нескольких панелях — достаточно вставить `[widget=N]` и в шапку, и в подвал.
- Названия виджетов видны только в панели администратора и не отображаются на сайте.
- Скрытие панели (`is_hidden = true`) убирает её из публичного просмотра без удаления содержимого и ссылающихся на неё виджетов.
