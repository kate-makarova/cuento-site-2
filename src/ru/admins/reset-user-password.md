<p class="docs-lead">Если пользователь потерял доступ к аккаунту и у него больше нет кодов восстановления, вы можете сбросить его пароль из панели администратора. Имейте в виду: эта операция навсегда уничтожает доступ ко всем существующим личным сообщениям пользователя.</p>

## Когда использовать

Используйте административный сброс пароля **только** при одновременном соблюдении двух условий:

- Пользователь не может войти и забыл пароль.
- Пользователь больше не имеет кодов восстановления.

Если коды восстановления у пользователя есть, он должен воспользоваться функцией **«Забыл пароль»** на странице входа. Этот путь перешифровывает существующий приватный ключ под новым паролем, и история переписки сохраняется. Административный сброс заменяет ключи полностью — это необратимо.

## Что происходит с личными сообщениями

Личные сообщения в Cuento защищены сквозным шифрованием. У каждого пользователя есть приватный ключ для расшифровки сообщений. При запуске административного сброса этот ключ безвозвратно деактивируется вместе со всеми копиями, привязанными к кодам восстановления.

Сами сообщения остаются в базе данных, но зашифрованы ключом, которого больше нигде не существует. Ни пользователь, ни вы, ни разработчики не смогут их восстановить. После завершения процедуры сброса пользователь получает новую пару ключей — она не может расшифровать сообщения, зашифрованные для старого ключа.

**Эта потеря постоянна и необратима.** Убедитесь, что пользователь понимает это, прежде чем приступать.

## Как сбросить пароль

1. Откройте **Панель администратора** и перейдите в раздел **Пользователи**.
2. Найдите нужного пользователя и откройте его профиль.
3. Нажмите **Сбросить пароль**.
4. Система генерирует одноразовый 6-значный PIN-код и показывает его вам один раз. **Скопируйте PIN сейчас** — он больше не будет показан.
5. Передайте PIN пользователю через любой внешний канал (сообщение на другой платформе, электронная почта и т. д.).

## Что делает пользователь дальше

Когда пользователь следующий раз попробует войти по своему имени пользователя:

1. Форма входа обнаружит ожидающий сброс и предложит ввести отправленный вами PIN.
2. После ввода правильного PIN пользователь задаёт новый пароль.
3. Система генерирует новую пару ключей и показывает новый набор кодов восстановления.
4. Пользователь должен сохранить новые коды восстановления, прежде чем сможет продолжить. Напомните ему сохранить их в надёжном месте — это единственный способ восстановить доступ или удалить данные в будущем.
5. После подтверждения сохранения кодов пользователь входит в аккаунт автоматически.

## Если PIN утерян

PIN показывается вам один раз. Если вы закроете модальное окно, не скопировав его, — восстановить его невозможно. Потребуется запустить сброс заново: будет сгенерирован новый PIN, а старый станет недействительным.
