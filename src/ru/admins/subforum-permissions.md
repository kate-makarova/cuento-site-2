<p class="docs-lead">Система прав доступа Cuento имеет два уровня: проверка глобальной роли и запись ACL для каждого подфорума. Оба должны пройти проверку, чтобы пользователь получил доступ к контенту подфорума.</p>

## Предоставление доступа

В административной панели перейдите к настройкам подфорума и добавьте пользователей в список доступа. Вы можете установить права только на чтение или полные права на постинг для каждого пользователя. Изменения вступают в силу немедленно — перезапуск не требуется.
