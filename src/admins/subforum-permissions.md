<p class="docs-lead">Cuento's permission model has two layers: a global role check and a per-subforum ACL record. Both must pass for a user to access subforum content.</p>

## Granting access

In the admin panel, navigate to a subforum's settings and add users to its access list. You can set read-only or full posting rights per user. Changes take effect immediately — no restart required.
