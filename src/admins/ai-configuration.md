<p class="docs-lead">Cuento's AI features — narration assist, game digest, and lore Q&A — are powered by a configurable AI provider.</p>

## Choosing a provider

Go to Admin → Settings → AI. Set `ai_name` to `claude`, `gemini`, or `openai`, then paste your API key into `ai_api_key`. The change takes effect immediately without a restart.

## Game digest

The AI game digest summarises recent forum activity and answers player questions about ongoing storylines. Configure the digest schedule and the subforums it covers from the admin panel.
